# Social profile marks

The developer card links to Mohamed Fooda's own profiles. These marks identify
the destination services; they do not imply endorsement.

- GitHub Invertocat black and white PNGs: unmodified files from
  https://brand.github.com/GitHub_Logos.zip, linked by
  https://brand.github.com/foundations/logo (retrieved 2026-11-05).
- LinkedIn blue [in] PNG: unmodified `LI-In-Bug.png` from
  https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip,
  linked by https://brand.linkedin.com/downloads (retrieved 2026-11-05).

Marks remain the property of their respective owners. The GitHub mark uses the
provided white variant on dark surfaces and black variant on light surfaces.
