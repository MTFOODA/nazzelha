# Nazzelha identity

The new icon was generated with the built-in `image_gen` tool, then refined with the same tool. The previous source asset is preserved.

- Final master: `assets/logo/nazzelha-v2.png` (transparent PNG).
- Native splash export: `assets/logo/nazzelha_splash-v2.png` (480 px, deterministic resize only).
- Generated Android resources, Windows ICO, web icons and favicon use the same master.
- Colors: royal blue/indigo, white, cyan. The mark combines an n, a play triangle, and a downward download arrow.
- Poppins and Tajawal are bundled with their OFL licenses in `assets/fonts/`.

## Generation prompt

Use case: logo-brand. Create one polished final app icon for Nazzelha, a cross-platform video and playlist downloader. Icon only, no text or lettering. A distinctive geometric monogram suggesting a lowercase n flowing into a bold downward download arrow, with a small negative-space play triangle integrated naturally. Bold simple silhouette legible at 24 pixels. Centered balanced mark in luminous white and electric cyan on a deep royal-blue to indigo rounded square tile. Restrained smooth gradient, flat crisp vector-like geometry, generous safe inset so Android adaptive masks never clip the symbol. Modern friendly reliable feel consistent with a blue/cyan Flutter application. Square composition, isolated on a genuinely transparent background outside the rounded tile. No mockup, no phone, no watermark, no extra icons, no surrounding labels.

## Refinement prompt

Refine this app logo into a pristine production icon. Preserve the exact central lowercase n, play triangle, and downward arrow concept, its white/cyan colors, composition and rounded blue/indigo tile. Clean all tile edges into perfectly smooth mathematically regular rounded rectangle boundaries. Remove every stray blue speck, rough pixel, paint-like fringe, texture and glow outside the tile. All pixels outside the rounded square must be completely transparent with clean antialiased edges. Inside the tile use smooth restrained gradients and crisp vector-like geometry, no texture, no added elements, no text. One centered icon only.
